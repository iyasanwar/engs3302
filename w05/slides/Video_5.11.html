Which model, when?

modelchoose it whenavoid it when
LDA
one shape		the clouds have about the same spread and tilt, or there are few points per classthe shapes clearly differ
QDA
a shape per class		the shapes differ, and each class has many more points than featuresa class has fewer points than features
naive Bayes
no tilt		the features are hardly correlated, or there are very many featuresthe features are strongly correlated
Now.So.Next.

Each model assumes a shape of the cloud. It wins when its assumption is close to the data.

LDA: one shape for all. Straight boundaries, and it learns from all the points together.

QDA: a shape per class. Curved boundaries, but it needs many points in every class.

Naive Bayes: no tilt. Very few numbers, but correlated features count the same evidence twice.

Count, look at the clouds, then test. A tie? Take the simpler model: fewer numbers, less luck.

LDA or QDA?

  1. QDA: 3 × 6 = 18; LDA: 6; naive Bayes: 3 × 3 = 9.
  2. Not QDA: each species has only 15 points for 20 features. Its Σ has no inverse, so the QDA score cannot be computed. QDA needs more points per class than features. LDA (one matrix from all 45 points) or naive Bayes.
  3. Straight: with the same shape the x² terms cancel, as in one feature. LDA is the right model.

Week 5 in four lines

Maximum likelihoodμ̂ = average, σ̂² = average squared distance (divide by n). Logs turn products into sums.
One featureSame spread: one threshold, x* = (μ₁ + μ₂)/2 + σ²/(μ₁ − μ₂) · ln(P(ω₂)/P(ω₁)). Different spreads: two or none.
CovarianceVariances on the diagonal, covariance off it; ρ gives the tilt. The Mahalanobis distance follows the tilt.
LDA · QDA · naive BayesShared shape: straight. Own shape: curved, more numbers. Naive Bayes ignores the tilt: few numbers, but with correlated features it counts the same evidence twice.
